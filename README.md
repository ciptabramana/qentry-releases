# QEntry releases

Installer packages for QEntry queue management. This repository holds no source code; download a package from **Releases**.

- `qentry-<version>-windows.zip` / `qentry-<version>-linux.zip`: realtime over WebSocket.
- `qentry-<version>-sse-windows.zip` / `qentry-<version>-sse-linux.zip`: the same release with realtime over Server-Sent Events.

Unzip into a `qentry` folder on the server and run `install.bat` (Windows) or `install.sh` (Linux). `SERVER_GUIDE.md` and `USER_GUIDE.md` inside the zip explain the rest (Bahasa: `*.id.md`).
